How to pronounce

Arabic has 28 letters (plus hamza ء, which sits on a seat such as أ ؤ ئ). Some letters are heavy (emphatic): ص ض ط ظ and غ خ ق, said with the back of the tongue pulled back and the mouth full. ح and ع come from the middle of the throat, while ه is a light breath. Short vowels: fatḥah (a), kasrah (i), ḍammah (u). Letters like ا و ي can be long vowels.

Voice tools need Chrome, Edge or Safari, and a microphone. The speech engine on your device is not a qari, so also listen to a trusted reciter.

Colours: silent madd 2 madd longer qalqalah ghunnah/ikhfā’/iqlāb idghām

Text, transliteration, translation and audio load from public Quran APIs (alquran.cloud, Quran.com). Tafsir is Ibn Kathir (abridged). Verify against a printed Mushaf and learn tajweed from a qualified teacher. “Check my voice” compares words only.

Backup & reset

Your progress lives in this browser. Export it now and then so you can restore it on another device.

Install the app

Install it like a normal app: it opens full-screen, works offline for the parts you have already loaded, and keeps your progress.

Offline listening

Downloads include the Arabic text, transliteration, translation and recitation audio, so you can read and listen with no internet. Tafsir needs a connection. The whole Qur’an takes a lot of space (about 0.5 GB or more) and time. You can pause and resume at any point.

iPhone / iPad

Open this page in Safari, tap Share, then “Add to Home Screen”.

Android

Open in Chrome, tap the ⋮ menu, then “Install app” or “Add to Home screen”.

Windows / Mac / Linux

In Chrome or Edge, click the install icon in the address bar (or ⋮ → “Install Quran & Arabic Learner”). It opens in its own window, with a desktop shortcut.

Installing needs the page to be served over HTTPS (or localhost). Microphone features also need HTTPS. Upload the whole folder to any static host, such as Netlify, GitHub Pages, Cloudflare Pages or Vercel.
